# 倒带 REWIND

录音倒放工具站 —— 把声音倒过来听。

纯前端单文件实现，无需服务器，双击 `index.html` 即可使用，也可部署到任意静态托管。

## 功能

- 麦克风录音（MediaRecorder）
- 上传 / 拖拽音频（mp3、wav、m4a、ogg 等）
- 一键倒放：真正的时间轴反转，波形同步掉头
- 变调滑块：-12 ~ +12 半音，播放中实时生效（磁带原理，变速同变调）
- 波形点按 / 拖动定位（同手机录音条）
- 下载倒放结果 WAV（含当前变调，OfflineAudioContext 固化）
- 会话记录面板：记录本次会话的录音 / 上传，可回放、删除、清空；关闭页面即自动删除（sessionStorage）
- 内置 5.5 秒示例旋律，离线可玩
- 响应式布局（桌面 / 平板 / 手机）

## 使用

双击 `index.html`，或直接访问线上版：<https://ailment-eng.github.io/rewind-app/>

## 说明

- 录音需要浏览器麦克风权限；线上 https 环境最稳，双击本地文件在 Chrome/Edge 下也可用
- 变调为磁带式（变速同变调），非保持时长的原速变调
